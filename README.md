# チクタクウォッチの大冒険　ソースコード
ゲームパレードURL：https://gameparade.creators-guild.com/works/3450<br>
タイトル：チクタクウォッチの大冒険<br>
世界観：あるところに、時計をこよなく愛し、大切に持ち歩いている少年がいました。<br>
       しかしある日、彼は大切な時計をどこかに置き忘れてしまいます。<br>
       少年はとても悲しみましたが、少年からたくさんの愛情を注がれてきた時計は、離れたくない一心で、なんと自ら動けるようになったのです<br>
       少年に会いたい一心で、ウォッチくんは旅に出ます。鍵と地図を手に入れ、少年の家へ帰る壮大な冒険が今始まる！<br>

開発環境：Unity, C#, Microsoft Visual Studio<br>
ステージ数全5ステージ<br>
ゲームジャンル：3Dパズルゲーム,箱庭脱出ゲーム<br>
開発人数：9人(リーダー:1人,ゲームプランナー:3人,プログラマー:2人(NKGdotcom),グラフィッカー:3人)<br>
ゲーム概要：主人公ウォッチくんを操作して、持ち主の元まで戻る3Dパズルゲームです。<br>
           プレイヤーはウォッチくんの能力「時間を進める、時間を戻す」を使って、何かが起こる前であったり何かが起こった後の状態に戻します<br>
           これらの機能を使いながら各ステージをクリアしていき持ち主の部屋にまで進んでいきます。

### 担当箇所
・タイトル、ステージ選択画面UI
・時間操作ギミック全般、時間の状態を管理するクラス作成
・クリア判定を管理するクラス作成
・ステージ1の水道、葉っぱの挙動
・ステージ3のルンバの挙動、本の挙動
・ステージ4のシンクの挙動
・クリア判定

### こだわった点
・時計を動かすUIギミックで、自分で時計を動かすだけでも楽しいと感じるようにポストエフェクトやドラッグ機能を用いました。<br>
・ステージ選択画面でクレヨンの色が塗られる演出を意識し、世界観に合ったUI画面を作成しました<br>
・ルンバの挙動でNavmeshを用いて経路探索機能を追加しました<br>
・ステージ4のシンクの浮遊感を上手く再現しました<br>
